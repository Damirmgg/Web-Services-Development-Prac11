# Feedback Collector — практическая работа модуля 11

Веб-приложение на Go для сбора отзывов. Пользователь вводит имя и сообщение, после отправки видит отзыв в общем списке. У каждого отзыва есть уникальный ID; на странице отображается общее количество. Данные находятся в `[]Feedback` в памяти и теряются при перезапуске сервера. Начальный список пустой.

## Запуск

Нужны Go 1.20+ и Visual Studio 2022/2026 с рабочей нагрузкой «Разработка классических приложений на C++» для проекта Makefile, как в модулях 09–10. Само приложение написано на Go, сторонних библиотек нет.

1. Распакуйте архив и откройте **FeedbackCollector.sln**.
2. Выберите **Debug | x64**, нажмите **Ctrl+F5**.
3. Оставьте окно сервера открытым и перейдите в браузере на **http://localhost:8080**.
4. Остановка сервера — **Ctrl+C** в его окне.

Альтернатива: выполните `go run .` в папке с `go.mod` и откройте тот же адрес. После установки Go перезапустите Visual Studio.

Практика и лабораторная используют один порт 8080: запускайте их по очереди. Шаблоны и CSS встроены в приложение через `go:embed`; после их изменения нужна пересборка. Swagger и база данных не используются.

## Маршруты

| Метод | Адрес | Действие |
|---|---|---|
| GET | `/` | Форма, отзывы и их количество |
| POST | `/feedback` | Добавить отзыв; поля `author` и `message` |
| GET | `/about` | Информация о приложении |

После добавления сервер возвращает `303` на `/`. Обновление страницы не создаёт повторный отзыв. Пустое имя или сообщение, включая строки из пробелов, возвращают `400` с понятной ошибкой. Уже заполненные поля сохраняются в форме. Неверный HTTP-метод возвращает `405`, неизвестная страница — `404`.

## Файлы

- `main.go` — структуры Feedback и PageData, срез отзывов, HTTP-сервер, маршруты, обработчики, проверка формы и вывод шаблонов. Mutex защищает список при одновременных запросах.
- `templates/index.html` — форма и список отзывов.
- `templates/about.html` — информация о приложении.
- `static/style.css` — оформление для компьютера и телефона.
- `go.mod` — описание модуля; `.sln` и `.vcxproj` — сборка Go из Visual Studio.

## Что показать на защите

1. Добавьте отзыв от Ивана Петрова: «Отличный сайт, всё работает!» — появится ID 1, счётчик 1.
2. Добавьте отзыв от Анны Сидоровой: «Удобный интерфейс и простая навигация.» — появится ID 2, счётчик 2.
3. Обновите страницу: оба отзыва сохранятся, число не изменится.
4. Отправьте имя или сообщение из нескольких пробелов: сервер покажет ошибку, счётчик останется 2. Полностью пустые поля также блокируются браузером через `required`.
5. Откройте «О проекте» и вернитесь на главную.
6. Откройте `/feedback` в адресной строке: GET-запрос вернёт `405 Method Not Allowed`.

Пустые поля можно проверить непосредственно на сервере из PowerShell:

```powershell
curl.exe -i -d "author=&message=Hello" http://localhost:8080/feedback
curl.exe -i -d "author=Ivan&message=" http://localhost:8080/feedback
```

Оба запроса возвращают `400`. Пакет `html/template` экранирует HTML из отзывов: введённые теги отображаются как текст. Редактирование и удаление отзывов не предусмотрены заданием.
